# What's planned

The bigger features Lattis doesn't have yet. Nothing here has a date, and the order means nothing. Plans change as I use the launcher.

- **Grid view.** Your games as a wall of covers next to the list, for browsing a large library by sight.
- **Heroic Games Launcher.** Show and launch your Epic, GOG and Amazon games alongside the rest.
- **Your whole Steam library,** not just what is installed, with the different versions of a game and the same game from several sources shown as one entry.
- **Installing games.** Move an install to another drive and back, run Windows `.exe` installers, and download games from sources you set up through plugins.
- **Disk usage by platform.** A pie chart of how much space your installed games take, split by platform.
- **Mod managers.** Working with the tools people use to mod their games.
- **Close to tray.** Keep Lattis running in the background with a tray icon, and hide the window instead of quitting while a game is running or Steam edits are waiting.
- **Controller support.** Browse and launch your games with a gamepad, and a bigger layout for a TV.
- **Multi-select.** Pick several games and hide, tag, favorite or change their emulator at once.
- **Collections.** Saved filters, plus a "Continue playing" row.
- **Ludusavi.** Back up saves before a game starts or after it closes, keeping the last few.
- **A command palette and drag and drop.** Jump to any game, setting or action from the keyboard, and drop ROMs or images onto the window.
- **A command line.** Launch or add a game from a script, and make desktop shortcuts for games.
